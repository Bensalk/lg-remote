# LG Remote

Android app and PWA to control an LG Smart TV over WiFi.

## Features

- Power, volume, channel, and navigation controls
- Works as an Android app (APK) or as a PWA in any mobile browser
- No cloud, no account — connects directly to your TV on the local network

## Install

Download the latest APK from [Releases](../../releases) and install it on your Android device.

Or open `index.html` in a mobile browser to use it as a PWA.

## Usage

1. Make sure your phone and TV are on the same WiFi network.
2. Open the app and enter your TV's IP address.
3. Use the remote controls.

**Tip:** Find your TV's IP address in the TV's network settings menu.
